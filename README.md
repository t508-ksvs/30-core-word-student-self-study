# 30 個核心單字｜字根字族學生自學版

學生學習網址：<https://t508-ksvs.github.io/30-core-word-student-self-study/>

## 開啟方式

直接雙擊 `index.html`，或將整個資料夾部署到 Netlify／GitHub Pages。

## 學生操作

- 左右方向鍵、Space 或底部按鈕翻頁。
- 手機可左右滑動翻頁。
- 單字旁的喇叭可播放核心單字發音。
- 「字族發音練習」中的每個單字都可點擊播放。
- 「核心圖／字族圖」可切換教師核心圖與學生延伸字根圖。
- 點擊圖片可放大。
- 「標記為已學會」會把進度保存在目前裝置的瀏覽器中，不需登入。
- `O` 開啟總覽，`F` 進入全螢幕。

## 檔案說明

- `index.html`：學生自學版主程式。
- `images/`：1–30 核心圖與統整複習圖的 WebP 優化副本。
- `extensions/`：`30字_分開字根` 的 39 張 WebP 優化副本。

原始 PNG 教材未被修改。
